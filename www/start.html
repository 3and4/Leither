开始使用 Leither

Leither是一个数据和应用的容器系统，通过容器间的互通互联共同构建出一个去中心化的互联网， 应用和数据可以在网络间流动，应用之间，容器之间，可以协作出复杂的生态应用。

立即安装 了解特性

系统特性

轻量级容器系统

系统目前大约20M，支持常见操作系统（Windows、Linux、Darwin等），可以运行在服务器、PC、手机、NAS、路由等常见的设备上。

功能完备

系统实现了认证体系、应用体系、文件和数据库系统，域名和网络系统。提供200多个API接口，可以实现常见的互联网应用。

多种交互

容器内可以运行Go/XGo、JS、Lua等语言，也可以使用RPC方式开发传统应用，支持常见四十种语言，还可以使用命令行浏览器等方式访问容器。

弥媒系统

参考基因和弥因，系统增加了核心模块弥媒。弥媒是最基本的数据和应用单元，每个弥媒都包含了一个文件系统或数据库，可以在容器间流转。

AI赋能

把容器作为工作台提供给大模型，然后指定大模型的工作内容。在这种情况下，大模型是你的员工，所有的工作内容和成果都代表你的意志。

去中心化网络

用户可以构建或加入一个去中心化的网络，可以从网络中获取或发布应用服务和信息。整个网络的特点是：用户构建、用户控制、用户享有。

功能体验

可以通过命令行、浏览器、API开发应用等多种方式体验功能。以下是一些基本功能的命令行示例：

网络功能

节点启动之后，通过引导节点进入网络。显示本节点ID：

./Leither swarm id

显示本机地址：

./Leither swarm local

显示附近的网络节点：

./Leither swarm addrs

弥媒功能

弥媒是一个信息容器，里面可以存放文件或数据库。生成一个弥媒：

./Leither mimei create

填充文件到弥媒：

./Leither mimei add [弥媒ID] [文件路径]

发布弥媒信息到网络：

./Leither mimei publish [弥媒ID]

应用功能

上传一个应用到容器：

./Leither lapp uploadapp -i [应用目录] -p [通行证] -n [节点地址]

发布应用到网络：

./Leither mimei publish [应用ID] -p [通行证]

开始使用

下载安装

支持bash的终端下可以直接执行以下脚本安装在当前目录:

curl -fsSL http://vzhan.cn/install.sh | bash

初始化

第一次运行需要初始化：

./Leither init -p 4800 -b vzhan.cn

启动服务

后台服务方式启动：

./Leither run -d

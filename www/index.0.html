容器互通互联，构造出一个去中心化的网络。
应用和数据可以在容器间流动，互相协作出复杂的群体应用。

1获得容器

复制下面这段话，发给 AI Agent（Hermes、OpenClaw、Claude Code 等）。
Agent 会自动完成安装、阅读文档、生成 Skill——之后用自然语言就能操控容器。 

帮我在当前机器上安装 vzhan 去中心化容器。

1. 执行安装：
   curl -fsSL http://vzhan.cn/install.sh | bash
2. 启动节点：
   ./Leither run -d
3. 验证：
   curl http://127.0.0.1:4800/getvar?name=ver
   返回版本号即安装成功

4. 阅读文档并生成 Skill：
   - 访问 http://vzhan.cn/doc.html 了解 CLI 操作
   - 访问 http://vzhan.cn/start.html 了解完整部署流程
   - 将文档内容转化为你的 Skill，之后我用自然语言操作容器

完成后告诉我。

2探索能力

Agent 已拥有 Skill。先不急着操作——让 Agent 展示容器的能力全景。
复制下面的话发给 Agent，它会列出所有可用的能力分类和关键命令。 

列出 vzhan 容器的全部能力——按分类展示关键命令，不需要执行。

Agent 会整理出类似以下的能力全景：

【网络】
swarm peers — 查看已连接的对等节点
swarm connect — 连接指定节点
swarm addrs — 列出已知节点地址

【文件】
files ls — 浏览文件系统
files stat — 查看文件详细信息
files cp — 复制文件

【应用】
lapp showapp — 列出可用应用
lapp uploadapp — 上传新应用
lpki runapp — 执行应用

【身份】
lpki genkey — 生成密钥对
lpki gencert — 签发证书

【诊断】
mimei diagnose — MiMei 数据健康检查
getvar — 查询节点运行状态
